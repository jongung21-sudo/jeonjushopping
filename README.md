# 전주이씨 (JEONJU LEE) - 공식 온라인 스토어

> **“TRADITION, REDEFINED.”**  
> 한국의 오래된 미감을 오늘의 방식으로 다시 만듭니다. 조선의 절제된 선과 현대 테일러링이 빚어낸 프리미엄 라이프스타일 & 패션 브랜드.

## 🏛️ 브랜드 소개
- **브랜드명**: 전주이씨 (JEONJU LEE)
- **핵심 키워드**: Korean Heritage, Modern Tradition, Minimal, Refined, Contemporary, Premium
- **디자인 철학**: 조선의 여백의 미, 수묵담채, 한지 텍스처, 절제된 선과 현대 럭셔리 미니멀리즘(Acne Studios, Lemaire 감성)의 융합

---

## ✨ 주요 기능 및 특징
1. **인터랙티브 수묵 비룡(飛龍) 커서**:
   - 조선 왕실의 기품을 담은 36관절 실시간 유기적 유영 물리 엔진.
   - 여의주, 4조룡 발톱, 유려한 두 가닥 수염, 은은한 먹물 안개 파티클.
2. **조선 수묵산수화 배경 & 캘리그래피 원화 로고**:
   - 정갈한 수묵산수화와 브랜드 캘리그래피 아트를 조화롭게 배치.
3. **완성도 높은 커머스 풀 스택 기능 (19개 페이지)**:
   - **쇼핑 & 탐색**: 홈, 전체 상품, 카테고리 필터링(Outer, Top, Pants, Accessories, Lifestyle), 상품 상세, 검색, 퀵뷰 모달.
   - **주문 & 결제**: 장바구니, 체크아웃(배송지/결제수단/쿠폰), 주문 완료.
   - **회원 & 마이페이지**: 로그인, 회원가입, 마이페이지, 주문 내역 조회, 위시리스트.
   - **브랜드 & 고객지원**: 브랜드 스토리, 공지사항, FAQ, 1:1 문의, 이용약관, 개인정보처리방침, 배송/교환 안내.
   - **관리자 콘솔**: 상품 관리, 주문 관리, 통계 대시보드.

## 🛠️ 기술 스택
- **Frontend**: React 19, TypeScript, Tailwind CSS
- **Bundler & Tooling**: Vite 6, PostCSS, Autoprefixer
- **Icons**: Lucide React
- **Typography**: Pretendard, Cormorant Garamond, Noto Serif KR

## 🚀 시작하기

### 1. 패키지 설치
```bash
npm install
```

### 2. 개발 서버 실행
```bash
npm run dev
```
브라우저에서 `http://localhost:3000/` 으로 접속합니다.

### 3. 프로덕션 빌드
```bash
npm run build
```
